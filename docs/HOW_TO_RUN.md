# How to Run the Reference Analytics Layer

This is only the **fallback / prototyping** layer.
The official submission must use the pipeline generated by PipeGen.

```bash
cd traffic-analytics-pipegen
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt

# Interactive (asks for video / webcam / RTSP)
python main.py

# Or non-interactive
python main.py --mode video --source /path/to/traffic.mp4
python main.py --mode webcam --source 0
python main.py --mode rtsp --source "rtsp://..."
```

Output appears in the `output/` folder (annotated MP4 + JSON counts).
